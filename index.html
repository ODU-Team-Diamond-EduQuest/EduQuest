Welcome to EduQuest

Welcome to EduQuest, a learning platform designed to make screen time more meaningful for children. EduQuest combines educational activities with parent-controlled screen time management to encourage learning while children use their devices.

Elevator Pitch

Children spend a lot of time using entertainment screens, displacing time that could be used to reinforce academic skills. EduQuest turns recreational screen time into an opportunity for learning by requiring children to answer short educational questions before entertainment apps unlock.

Problem Description

Reading and math scores among 9-year-old students have dropped to their lowest levels in decades. Meanwhile, children ages 8 to 12 average approximately 5.5 hours of recreational screen time each day (Rideout et al., 2022), displacing time that could be used to reinforce foundational academic skills.

Customer and End User

EduQuest is being developed for parents of children ages 8 to 12 who want a way to balance recreational screen time with academic reinforcement, without resorting to blunt tools like hard time limits or full app blocking. These are parents who already care about limiting screen time using tools like Apple Screen Time, Qustodio, or Bark, but are frustrated that existing options only restrict and not give a productive alternative or build in any academic upside. The secondary user is the child themselves, who interact directly with the question-answering interface to unlock additional screen time.

Solution Statement

EduQuest is a mobile application controlled by parents that combines screen time management with educational practice. The application allows parents to set screen-time limits and requires children to complete age appropriate questions to earn additional screen time. Parents are also able to monitor learning progress over time.

Explore our website to learn more about our project, meet our team, view our project documents, and see our feasibility presentation.

About EduQuest

EduQuest is an intelligent, parent-controlled screen time management and learning platform that transforms passive device usage into active micro-learning sessions while giving parents total administrative oversight.

Glossary

Term Definition
Academic Reinforcement A practice that helps strengthen educational concepts a child is already learning.
API (Application Programming Interface) A way for different parts of a software system to communicate and exchange information (“API”).
Backend Server The part of the system that handles data, requests, and other processes behind the scenes.
Built-in Question Database A collection of educational questions provided by EduQuest.
Cloud Computing Using internet-based servers and services to run applications and store data (Mell and Grance, 2011).
Container An environment that contains an application and what it needs to run effectively (“What Is a Containter”).
Cross-Platform Software that is designed to work on more than one operating system (“Build for and Integrate”).
Custom Questions Custom educational questions created by parents.
Docker A platform used to package and run software in containers so it can work across different environments (“What Is a Docker”).
FCM (Firebase Cloud Messaging) A Google service that is used to send notifications to devices and applications (Firebase Cloud Messaging).
Flutter A service used to build applications that can run on multiple platforms using one codebase (“Build for and Integrate”).
Load Balancer A tool that sorts incoming requests across multiple servers to prevent one server from handling too much traffic (“What is Elastic Load Balancing”).
Parent Control Dashboard The main area where parents manage screen-time limits, questions, rewards, and their child's progress.
Parental Controls Settings that allow parents to manage how their child uses EduQuest, including screen-time limits and rewards.
PostgreSQL The database system EduQuest will use to store account information and other application data (“About PostgeSQL”).
Progress Tracking A feature that records a child’s educational activity and performance over time.
React Native A service used to build mobile applications for platforms using one codebase (“React Native”).
Recreational Screen Time Time spent using digital devices mainly for entertainment, such as games or videos.
REST A common way for applications to request, send, and receive information through an API (“REST”).
Screen-Time Limit The amount of recreational device time a parent allows a child before additional time must be earned.
Screen-Time Management The process of setting and managing how much recreational time a child can spend on a device.
Screen-Time Rewards Additional device time a child earns by successfully completing required educational questions and activities.
TLS (Transport Layer Security) Technology used to protect information when it travels over the internet (Rescorla).
