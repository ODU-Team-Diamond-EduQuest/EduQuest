# Program Overview

EduQuest is a parent-controlled mobile application that combines screen-time management with educational practice. The application allows parents to set recreational screen-time limits and requires children to complete age-appropriate 
educational questions to earn additional screen time. Parents are also able to monitor their child's learning progress over time.

EduQuest is designed around four primary functions:

- **Set:** Parents set recreational screen-time limits.
- **Learn:** Children answer age-appropriate reading and math questions.
- **Earn:** Completed questions earn additional recreational screen time.
- **Track:** Parents monitor question performance, screen-time activity, and learning progress.

EduQuest is intended to support educational practice and reinforcement while giving parents continued control over their child's recreational screen-time settings.
